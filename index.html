使用帮助

  1. 创建试题模板：推荐用「智能识别导入」上传试卷（及可选答案）PDF/Word，系统自动识别出题号、分值、题型，快速核对后保存；也可手动逐题录入。一次建好可复用于多场考试。
  2. 创建考试：选择科目与模板，填写考试名称和日期，上传试卷/答案 PDF 或 Word 作为归档（可在系统内在线预览）。
  3. 导入成绩：从阅卷系统导出的 Excel（每行一个学生、每列一个小题得分），或使用系统下载的录入模板填写后导入；也可直接在线录入。
  4. 生成报告：点击"生成分析报告"，系统按规则引擎自动完成逐题评价与整体评价。
  5. 导出下载：导出《班级整体分析.xlsx》或《学生个人评价报告.xlsx》供老师、学生使用。
  6. 数据备份：数据保存在本地浏览器。建议定期在右上角"备份数据"导出 JSON 存档，换设备时"恢复数据"导入。
  7. 上线发布：本系统为纯前端应用，可部署到任意静态托管平台（Netlify / Vercel / GitHub Pages），几分钟即可获得可分享给师生的公网链接。详见部署指引。
